# Contributing Guide

Contributing to Masonite is simple:

- Open an [issue](https://github.com/masonitedev/masonite/issues) to ask any questions you need or to report bugs.
- Open a [pull request](https://github.com/masonitedev/masonite/pulls) to contribute to the core source code development of the project.
- Check the [repository](https://github.com/masonitedev/masonite) to get updates about tips and tricks, announcements and releases.
